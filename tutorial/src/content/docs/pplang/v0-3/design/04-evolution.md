本教程只教授 v0.3。下面的历史用于解释设计动机，不要求读者学习旧语法。

## 最小闭环

早期 pplang 先证明 `.pp` 可以经过手写 lexer、递归下降 parser 和 LLVM codegen，生成 JIT 程序、可执行文件与裸机输出。变量、函数、控制流、struct、extern 和指针构成了第一条闭环。

它证明了“能编译”，但一些语义仍像宽松的 C：整数可以冒充条件，字符串边界不统一，作用域、无符号运算和类型推断存在债务。

## 语义收敛

下一阶段没有急着增加大语法，而是先兑现基础承诺：

- `if`/`while` 只接受 bool。
- 无符号类型使用正确的除法、余数与比较。
- block 具有真正的词法作用域。
- `str` 统一为 `{ptr,len}`，切片执行边界检查。
- 数组只保留 `[N]T`。
- tuple、指针接收者、enum 和穷尽 switch 进入语言。
- `Buf` 与 `StrMap` 证明标准库可以承担容器能力。

## v0.3：显式类型复用

真实代码出现大量只差元素类型的结构与算法，v0.3 加入函数、struct 和 enum 泛型。所有类型实参显式写出，模板需要的比较、哈希或分配能力通过普通函数参数传入，再由编译器单态化为具体实例。

```pp
let answer: int = identity[int](42);
```

v0.3 因而不是“功能最多”的版本，而是第一条适合长期教学的冻结基线：核心语义、规范、编译器、标准库、ppdb 和 ppos 已经相互验证。

:::note[v0.3.x 的含义]
后续可以修复编译器缺陷、改善诊断和澄清文档，但新增语法或破坏性语义必须进入新的语言版本。本教程不会混入未实现的未来特性。
:::
