表达式操作数和函数实参从左到右求值。赋值不是表达式。

## 二元优先级

从低到高，所有二元运算符左结合：

| 级别 | 运算符 | 含义 |
|---|---|---|
| 1 | `||` | bool 或 |
| 2 | `&&` | bool 与 |
| 3 | `|` | 按位或 |
| 4 | `^` | 按位异或 |
| 5 | `&` | 按位与 |
| 6 | `== != < > <= >= in` | 比较与成员判断 |
| 7 | `<< >>` | 移位 |
| 8 | `+ -` | 加减、指针偏移 |
| 9 | `* / %` | 乘除余数 |

一元 `- ! ~ & *` 的优先级更高。字段、方法调用、下标、切片和 `as` 是最高层后缀操作。

## 调用与访问

```pp
add(1, 2)
identity[int](1)
point.x
point.move_by(1, 2)
values[0]
text[1:4]
value as u64
```

普通函数调用可以省略泛型实参；泛型函数和泛型方法必须写完整类型实参。方法调用是首参数调用糖，不引入动态分派。

## 成员判断

`x in array` 检查数组元素相等，`byte in str` 检查字符串字节。结果类型是 bool。

## 构造表达式

```pp
Point { x: 1, y: 2 }
[1, 2, 3]
(true, 7)
Result.Ok(7)
Option.Some[int](7)
```

数组字面量元素类型必须一致；tuple 至少两个元素；enum 变体的实参必须与 payload 声明一致。
