## 类型一览

| 类别 | 类型 | 规则 |
|---|---|---|
| 有符号整数 | `int` | i32，有符号除法、余数和顺序比较 |
| 无符号整数 | `u8/u16/u32/u64` | 对应位宽，无符号除法、余数和顺序比较 |
| 浮点 | `float` | f64 |
| 逻辑 | `bool` | i1，只能为 `true/false` |
| 字节视图 | `str` | `{ptr,len}`，不拥有内存 |
| 定长序列 | `[N]T` | N 是编译期整数，长度属于类型 |
| 裸指针 | `*T` | 系统边界类型 |
| 函数指针 | `fn(T1,T2)->R` | 无返回值时省略 `-> R` |
| tuple | `(T1,T2,...)` | 至少两个元素 |
| 具名类型 | struct/enum | 每个声明和泛型实例具有独立名义 |

`void` 只能作为无返回值函数或函数指针的返回类型，不能声明普通值。

## 声明与推断

```pp
let explicit: int = 1;
let inferred = 1;
let zeroed: u64;
```

局部变量可以从初始化器推断类型；无初始化器时必须写类型并零初始化。同一词法作用域不能重复声明同名变量。

## 匹配与转换

struct、enum、tuple、数组与函数指针要求精确匹配。`Option[int]` 和 `Option[str]` 是不同类型，两个不同声明即使字段相同也不是同一名义类型。

整数与 bool、aggregate 之间不存在隐式转换。跨整数/浮点、整数/指针以及收窄操作使用 `as`。转换只改变表示，不赋予所有权或有效性保证。
